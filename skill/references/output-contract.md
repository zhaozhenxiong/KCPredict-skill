# 统一输出约定

适用于 ICT 验证、条件计划及 KCPredict 综合分析。按用户范围省略未请求的方法；请求了但不可用的字段应保留原因。

对普通股票分析，默认交付最近3个月的结构／量价／ICT／未来5日单文件 HTML 交互综合图；回答提供 HTML 入口、内嵌 PNG 预览及 PNG/SVG 下载链接，并用短文说明共振或冲突。历史与预测沿同一条连续时间轴衔接，实际截止线明确区分真实行情与模型采样情景。保留通过／未通过／不可用／未执行四种预测质量状态；交互或重新布局不改变已评估路径和参数。图的来源、标注和质量状态契约见 [综合图说明](chart-workflow.md)。不把 Markdown 图片路径只写成普通文本。

## 标的、数据与结论

报告标的／交易所、请求截止、实际行情截止、数据来源和价格口径；多周期说明偏向／结构／触发各用哪个周期，未闭合桶单列。使用历史数据时不能称为实时。

对于待验证 ICT 设定，给出一个最终 `confirmed | developing | invalidated | no-trade`，方向为 `long | short | neutral`，并用一句话说明。最终状态是基于当前截止的上下文裁决，不照搬 `mechanical_status`；脚本的 `final_status=not_assessed` 不是第五种交易状态。已有多空候选时，最终状态覆盖当前用户观点或选定设定，其余候选保留为冲突／替代条件。

## 证据表

| 方法／层 | 观察与价位 | 锚点／确认／实际可用时间 | 分类及可用性 |
|---|---|---|---|
| CZSC | 已确认笔、中枢、来源 B/S 及失效边界 | 原字段 | observed / derived；available / partial / unavailable |
| 威科夫／量价 | 事件、供需及支持事实 | 原字段 | 同上 |
| ICT 偏向／区间 | 高周期、区间锚点、premium/discount | 对应闭合 K 线 | derived / interpretive / missing |
| ICT 流动性 | 扫荡参考、穿越与收回、目标是否仍有效 | 锚点与确认分列 | observed / derived / missing |
| ICT 位移／FVG | 三根 K 线、严格边界、CE | 第三根闭合时间 | derived / missing |
| ICT 结构／回撤 | 收盘突破的 swing、PD array、回撤是否守住 | 各自实际确认时间 | observed / derived / missing |
| 时间／事件／成本 | 是否适用、已核验或缺失 | 对应市场时区与日期 | observed / missing / not_applicable |

`observed` 是输入直接包含的事实，`derived` 是机械计算，`interpretive` 是偏向或流动性意图等解释，`missing` 是缺失。不能把对主力意图的推测归为 observed。

## 门槛与条件

逐项标 `pass / fail / unverified / not_applicable`：高周期前提、有意义 sweep、位移＋严格 FVG、收盘结构突破、区间位置、有效回撤、未失效／未过期、实际可行性、净 R:R ≥ 2。`not_applicable` 只用于本市场／周期不适用的条件，不能用来跳过反转模型的 sweep/MSS/FVG。任何必要项失败或不可核实都不支持最终 `confirmed`。

存在条件计划时说明：

- 触发：具体周期收盘或回测条件；精确价位不可核实时保留 `unverified`。
- 区域：FVG／经验证 OB／Breaker 的上下沿，及使用 CE／MT／OTE 的理由。
- 失效：价位、触发方式和结构原因；是否需要缓冲以及所用假设。
- 目标：最近对侧流动性及更远目标，核查是否已经消耗；分别列毛 R:R 和基于已知成本的净 R:R。
- 时效：截止日期／事件／结构失效；过期或错过入场时用 `no-trade`。
- 缺失：高周期、分钟数据、闭合信息、事件／公司行为、滑点、费用、交易规则、可做空性等，并说明阻止什么结论。

沪深看空结构可用于持仓风险观察，不推导可执行裸空。不要生成订单、目标仓位或成交结论。

## 预测与交叉解释

请求 Kronos 时，单列预测 `quality.prediction_usable`、缺失原因、设备、参数、中位路径及 P10–P90。上涨采样比例不是校准概率。模型路径仅是未来条件情景，不是已发生 ICT 证据，也不能替代未收盘确认。

最后点明哪些方法支持同一方向、哪里冲突、下一步需看到什么；不要把同一价格行为被不同标签重复描述当作多个独立信号，也不承诺胜率或机构参与。
