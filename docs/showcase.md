# 可视化功能导览

KCPredict 将结构、量价、ICT 和未来路径放在一张连续时间轴上。交互 HTML 适合查看细节，PNG 适合快速预览，SVG 适合放大和排版；三种输出共用 [报告主题](../skill/assets/report-theme.json)。

解压演示包，用浏览器打开其中的 `kcpredict-showcase-64.html` 即可。HTML 已内嵌数据、样式和脚本，无需联网、启动服务或安装运行时。GitHub 仓库中的 HTML 文件页用于查看和下载源码，不是在线运行入口。

## 可以查看什么

| 特色 | 展示方式 |
|---|---|
| 历史与未来衔接 | 预测从最后一个闭合日收盘价接出；截止线、蓝色背景和虚线区分历史事实与模型情景。 |
| CZSC 结构 | 显示确认笔、形成中笔、回溯中枢及来源标签；锚点与确认时间分开。 |
| 威科夫量价 | 成交量与此前20日均量共用时间轴，保留连续供需方向、相对量与最新事件。 |
| ICT / SMC | 查看扫荡候选、严格三K线 FVG、MSS 参考，以及确认日期和生命周期；机械证据不会自动升级为最终确认。 |
| 未来逐日明细 | 展示收盘中位数、P10–P90、相对末收盘变化与模型中位量。 |
| 质量状态 | 明确通过、未通过、不可用和未执行；查看有效样本数量、比例、门槛及缺失原因。 |
| 统一外观 | HTML、PNG、SVG 共享灰蓝工作台背景、红涨绿跌、蓝色笔、右侧价格轴与方法证据侧栏，并记录同一主题身份。 |

## HTML 交互

1. 用“完整窗口”查看三个月，用“20根＋预测”放大近期结构与未来五日。
2. 滚轮缩放、拖动平移；移动到K线或未来日期查看数值，点击可锁定日期；使用“取消固定”或 Esc 解除。
3. 切换结构、ICT、预测、分位带、有效样本路径和成交量图层。默认隐藏单条样本线，完整数据仍保留。
4. 在右侧“事件与依据”以及“历史结构与确认时间”“未来逐日明细”“数据与质量”中核查结论、日期、参数和质量原因。
5. 查看确认时间与生命周期，或导出当前示例的内嵌数据。

## 固定示例与质量

| 项目 | 本示例 |
|---|---|
| 标的 | 002436.SZ |
| 历史窗口 | 2026-07-16至2026-10-16，61根闭合日线 |
| 未来交易日 | 2026-10-19至2026-10-23，共5个交易日 |
| 请求／有效／无效采样 | 64／47／17 |
| 有效率／门槛 | 73.4375%／80% |
| 预测质量 | 未通过，`prediction_usable=false` |
| 行情来源资格 | 用户声明数据，未独立外部认证 |
| ICT 最终状态 | 尚待最终核验，`not_assessed` |

这是固定历史研究样例，不是实时行情。分位区间来自47条有效路径，上涨样本比例不等于校准概率或历史胜率；交互、换主题和导出都不会改变证据或质量结果。文件身份和主题 SHA 见 [展示资产清单](assets/showcase-manifest.json)。

## 生成自己的报告

准备独立运行时、自己的行情、核验交易日历和固定模型权重后，在项目目录运行：

```sh
python skill/scripts/kcpredict_report.py --symbol 002436.SZ
```

默认最近3个月、未来5个交易日、64条采样。使用自己的数据与实际截止，不会自动取得本示例的行情或复用示例数字。安装与数据准备见 [项目说明](../README.md)，输出和迁移细节见 [综合图工作流](../skill/references/chart-workflow.md)。
